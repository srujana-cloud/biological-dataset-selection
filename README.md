Biological Dataset Selection

1. Dataset Name

Human Breast Tumor Gene Expression Dataset

2. Database

NCBI Gene Expression Omnibus (GEO)

3. Accession Number

GSE38708

4. Organism

Homo sapiens (Human)

5. Dataset Source

https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE38708

6. Dataset Description

This dataset contains gene expression information from eight primary human breast cancer samples. The samples were studied using microarray technology to understand gene expression patterns in breast cancer.

7. Dataset Information

- Number of samples: 8
- Experiment type: Expression profiling by array
- Platform: Illumina HumanRef-8 v2.0 expression beadchip
- Organism: Homo sapiens

8. Research Question

Which genes show different expression patterns in human breast cancer samples?

9. Applications

- Gene expression analysis
- Identification of important genes
- Understanding breast cancer biology
- Bioinformatics data analysis

10. Conclusion

Public biological datasets help researchers study gene expression patterns and understand diseases using computational methods.
